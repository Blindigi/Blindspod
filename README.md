# Blindpodcast

Blindpodcast is een intuïtieve webapp ontworpen om efficiënt naar audiobestanden te luisteren en specifieke fragmenten vast te leggen. Voeg eenvoudig audiobestanden toe via een directe URL en markeer belangrijke momenten met bladwijzers. Dankzij de volledige ondersteuning voor schermlezers is de app toegankelijk voor iedereen. 

## Belangrijkste functionaliteiten

* **Web-based**: Direct te gebruiken in de browser zonder installatie.
* **Audio via URL**: Stream audiobestanden direct door een link te plaatsen.
* **Bladwijzers aanmaken**: Markeer specifieke tijdstippen tijdens het luisteren.
* **JSON Export**: Sla je bladwijzers op in een gestructureerd JSON-bestand.
* **JSON Import**: Laad je opgeslagen JSON-bladwijzers moeiteloos weer in.
* **Schermlezer toegankelijk**: Volledig geoptimaliseerd voor software zoals VoiceOver of NVDA.

## Gebruikte technologieën

* **HTML5**: Voor de semantische en toegankelijke structuur van de webapp.
* **JavaScript (Vanilla)**: Voor de audiofunctionaliteit en de verwerking van de JSON-data.

## Handleiding voor lokaal gebruik

Volg deze stappen om de webapp lokaal op je computer te draaien:

1. **Download de code**: 
   Kloon deze repository of download de bestanden als een ZIP-bestand en pak dit uit.
   ```bash
   git clone https://github.com
   ```
2. **Open de app**:
   Dubbelklik op het bestand `index.html` om de applicatie direct in je favoriete internetbrowser te openen.
3. **Audio afspelen**:
   Open Instellingen, Podcast toevoegen. Plak een directe link naar een audiobestand (bijvoorbeeld een `.mp3` of `.wav` URL) in het invoerveld en klik op laden.
4. **Bladwijzers beheren**:
   Maak bladwijzers aan tijdens het luisteren. Gebruik de knoppen 'Exporteer' en 'Importeer' om je bladwijzers op te slaan of te laden via een `.json` bestand. Je kunt de bladwijzers ook hernoemen en/of verwijderen via Instellingen (Bewerkmodus).
